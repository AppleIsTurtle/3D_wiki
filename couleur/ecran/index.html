Écran

L'écran est la dernière étape de la chaîne : il transforme des valeurs codées en lumière, avec ses propres limites.

Deux écrans qui reçoivent le même fichier n'émettent pas la même lumière. Or tu juges tes images à travers le tien, dans ta pièce.

Les références : un écran de bureau sRGB est prévu pour un blanc à 80 cd/m², la vidéo HD pour 100 cd/m² dans une pièce tamisée à 10 lux, avec un point blanc D65 dans les deux cas.

Calibrer, profiler

Calibrer, c'est régler l'écran vers une cible : luminosité, point blanc, courbe. Profiler, c'est mesurer le résultat avec une sonde et le décrire dans un profil ICC, que les applications gérées utilisent. Les deux vont ensemble. Une calibration matérielle s'écrit dans l'écran lui-même ; une calibration logicielle passe par l'ordinateur.

Windows 11 peut aussi gérer la couleur de toutes les applications (Auto Color Management), avec un matériel compatible et un profil d'écran adapté. Sur Mac, ColorSync gère la couleur pour la plupart des applications.

À retenir

  • L'écran, le système et la pièce font partie de la chaîne.
  • Un écran large gamut sans gestion rend le sRGB trop saturé : pour travailler en sRGB, utilise son mode sRGB s'il existe.
  • Pour juger du SDR sous Windows, coupe le mode HDR.
  • Seule une sonde dit ce que ton écran émet vraiment.
Pour aller plus loin

Windows

Sans « Advanced Color » (Auto Color Management ou mode HDR), Windows ne gère pas la couleur de ce qu'affichent les applications : il suppose tout en sRGB. Auto Color Management est disponible depuis Windows 11 22H2, avec une carte graphique récente et un profil d'écran MHC. Il se règle dans Settings > System > Display > Color profile (libellés de l'interface anglaise). En mode HDR, le curseur de luminosité du contenu SDR fixe le blanc des applications SDR ; plusieurs utilisateurs constatent que Windows décode alors le SDR avec la courbe sRGB par morceaux, ce qui relève les ombres d'un contenu prévu pour un gamma 2,2. Microsoft ne le documente pas.

Les dalles

IPS : contraste d'environ 1000:1, angles de vision larges. VA : contraste plus élevé, mais teintes qui changent avec l'angle. OLED : noir par pixel, mais luminosité qui baisse quand une grande surface est claire.

macOS

ColorSync gère la couleur pour la plupart des applications. Avec l'EDR, macOS peut afficher au-dessus du blanc SDR ; la marge dépend de l'écran et de la luminosité choisie.
